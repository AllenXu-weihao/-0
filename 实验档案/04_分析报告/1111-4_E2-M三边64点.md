# 第四批：三边 64 点网格

种子 1105 的同一 80 帧上，64 个配置的 10 dB 候选错都是 61/480，全部标为固定回归可行。按预登记的搬运代理，统一总宽 U 和逐边总宽 M 的最低成本都是 `W15_15_15` 的 59400 bit/向量，所以 (CU−CM)/CU = 0。在这个网格和这个代理里，允许三条边各选总宽没有少搬运逻辑位。`W15_15_15` 已经是 {15, 17, 19, 21} 的下界，不能据此再往更窄外推。没有冻结格式。能耗待测。69 错只是这份回归的门槛，不是误码率证明。

运行 `E2-M_grid64_s1105_a01_20261111_002256_tpc21d47e0_0131_4d3e_aae0_ac1aea8e91f1`。开工时代码是 `5e6b81d`。输入是第三批 manifest 指向的 E0 `inputs.mat`。桥接先重放了 float、mild 和 joint_W21，逐帧错数、两向翻转、最大 |ΔLLR| 和饱和与第三批一致，然后才把 W=(21,21,21) 当作网格的一格复用。整数位含符号仍是 alpha 9、raw 8、β 7。阻尼仍是运行时的 0.3，不是 307/717。

## 成本

C = 1080·Wα + 1080·Wraw + 1800·Wβ。四条对角线的可行最低值 CU 和全部 64 点的可行最低值 CM 都是 59400，并列集合里只有 `W15_15_15`。M 包含 U，CM 没有大于 CU。10/20/30 dB 的错数在 64 点上都与浮点相同，分别是 61、5、0；这三个信噪比的硬判差也全是 0。门槛没有把任何一格挡在外面，所以逐边放宽找不到更便宜的可行点。

0 dB 不是这样。浮点是 190 错。64 点的 0 dB 候选错在 176 到 188 之间，都比浮点少，但少是因为错变对多于对变错，不是更接近浮点。硬判差全部发生在 0 dB，范围是 13 到 50。

## 饱和

饱和不单独淘汰。正饱和只出现在六条边上，分母是元素数：`sum_exp` 1/4800，`mix_b` 662/69120，`A5_x` 6/51840，三格都不变。`mix_a` 在 13126 到 13130，分母 69120。`ai` 在 15018 到 15027，分母 43200。`A5_acc` 是 4276 或 4277，分母 51840。raw 的饱和是 0。`W15_15_15` 的分边计数是 sum_exp 1、mix_a 13127、mix_b 662、ai 15020、A5_x 6、A5_acc 4277。`W21_21_21` 的 ai 是 15025、A5_acc 是 4276，总饱和 33097，与第三批联合起点一致。
