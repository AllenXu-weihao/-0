# 第五批 MATLAB 任务书：三套字长配置的跨样本配对复测

## 为什么现在换样本

第四批的 64 格、5,120 条配置×帧记录已核对。按原协议，统一总宽 U 与逐边总宽 M 的最低逻辑搬运代理均为 59,400 bit/向量，唯一最低点为 W15_15_15，额外节省为 0%。原因是允许的最窄统一点已经可行，任何逐边增宽都会增加正权重成本。这个结论适用于本批候选域和固定回归判据。

同一 10 dB 样本反复用于扫宽，64 次比较共享同样的 20 个独立向量。全都得到 61/480 错，只说明在这 20 帧上没有区分开。0 dB 则看到 13 至 50 位硬判变化。下一次先检验这些现象在新输入上能否复现。本批是开发复测，E4 继续封存。

## 冻结比较：一个数据集，三个配置，一条参考

|候选（顺序为 alpha / raw / β 的总宽）|固定角色|第四批 C（bit/向量）|第四批 0 dB 硬判分歧 / 480 bit|
|---|---|---:|---:|
|15 / 15 / 15|原协议下唯一最低成本点|59,400|50|
|21 / 19 / 17|诊断对照：在第四批与宽点逐帧摘要相同的六格中成本最低|73,800|13|
|21 / 21 / 21|较宽联合锚点|83,160|13|

三个候选共享原始 float 参考。固定 mild 其余所有量化点与矩阵运算次序，三边整数位固定为 9/8/7，F=W−I，阻尼沿用运行时 0.3；复用第四批格式构造逻辑。第五批不搜索更多格式，不用硬判分歧重新评选第四批的赢家。

1. 从仓库根建立独立 run，例如 `new_run('E2-M','cross_sample_three',271111,1)`。预登记比较对象、运行代码与部署包哈希、样本预算和指标；建新驱动复用第四批数值逻辑，不调用会续跑并写入旧 run 的批处理入口。用历史 seed 1105 的归档输入作一次三候选桥接：分别复现分档错数、翻转方向、逐帧最大 LLR 差与饱和（CSV 浮点容差按原始输出精度）。失败先查算术或配置差异。
2. 新开发样本固定 `make_cases(512,271111)`，四档背景 SNR 各 512 个独立向量、12,288 bit，总计 2,048 个向量。确认开发种子未用于历史结果或任何验收集；若已占用，在读取新输出前登记替代种子。输入一次生成归档，float 与三候选逐帧复用，不以结果决定何时停止。完整底表应有 6,144 行配置×帧。E4 的 9110527 不使用。
3. 对照必须以原始帧和候选标识配对。逐帧保存相对发送真值的错数、两向翻转、LLR 最大差与饱和；另保留全部 24 个末轮 LLR、硬判和真值，使三候选之间可直接比较。尤其对 21/19/17 与 21/21/21 逐分量比较，分别报两者硬判分歧和最大 LLR 偏差；旧摘要相同不能推出两者所有软值相同。每条正饱和边记录次数、有效元素分母与位置。
4. 主图按 SNR 列三个候选相对 float 的配对 ΔBER 与双向翻转，并单列新样本和历史样本。对每个向量计算（候选错数−浮点错数）/24；以独立向量为单位分档作配对 bootstrap（10,000 次、固定分析种子 271112），给出探索性区间。全零差或极少非零帧时保留原始分子/分母，不将退化的零宽区间解释为无风险。若一档完全没有硬判分歧，可列独立帧“至少一位发生分歧”的单侧 95% 上界 1−0.05^(1/512)。固定 480 bit 的 69 错门槛仅用于历史桥接；新样本的 ΔBER 以 8/480 标参考线，不作正式验收。
5. 重点看新 10 dB 的分歧是否出现，以及 0 dB 的 50 对 13 的差异在扩大样本后是否仍表现为较高的翻转频率。若出现，选最小 case_index 的新 10 dB 翻转帧，再选一例 0 dB 代表帧；对三配置同帧追踪 idx、raw、旧/新 β、末轮两组峰值与 LLR。若没有翻转，选软值偏差最大的帧，明确选择规则。汇总、报告、脚本和输入摘要均入档，更新运行索引及交接入口。

## 结果将怎样改变决策

- 若最低成本点出现较宽点没有的可重复退化，定位首次分歧，下一份协议只回退有证据的一条边，保持其余边不动。
- 若三点的精度仍难区分，报告样本预算和不确定性，保留 W15_15_15 为原回归下的成本候选。下一步优先检验有实际硬件影响的阻尼舍入/算术合同；同域 E3-H 无法比已知的成本下界更低。若要研究搜索效率，需另定义预算与比较问题。
- 若 21/19/17 与宽锚点在新样本上表现不同，明确差异属于硬判还是软值。成本差 9,360 bit/向量来自上批预设的逻辑模型；不能计作已节省的 DSP、BRAM 或实测能量。
- 本批到三配置复测和诊断报告为止，未做 FPGA 综合，未作独立样本正式非劣判定。交接时附 run_id、底表、图和一句由数据支持的决策。
