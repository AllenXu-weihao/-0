## A. 架构概览与工作原理

优化目标先写死：**数字 IC 动态能量 / 信息比特**，FPGA 用来定拍数、证功能、拆模块面积。吞吐效率（吞吐/LUT）作辅表，与 1BOX Table I 同类，但不是本任务的停手条件。

模块点名（信号名与 `MIMO.m` / `位宽管理.txt` 同字）：

| 模块 | 对应推断步骤 | 完整功能 | 去掉 MVM |
|---|---|---|---|
| CTRL | 3 轮计数、stage、握手 | 有 | 有 |
| MVM-A2 | `[beta,local]→alpha` | 稀疏 MAC，扇入≤5 | 端口 |
| NRM+SORT | 20 口减最大 + 稳定降序 | 有 | 有 |
| STAT+LAMBDA | μ、σ²、8×4 mix、ai 的 LSE | 有（先按 FP32 规格） | 有 |
| MVM-A13 | `[lambda,ai]→score` | 稀疏 MAC，扇入≤6 | 端口 |
| UNSORT+DAMP | 还原顺序、减最大、rate=0.3 | 有 | 有 |
| MVM-A5 | `[beta,local]→z(36)` | 稀疏 MAC，扇入≤6 | 端口 |
| H-MEM / W-ROM | `H` 每帧、`A*` 系数码本 | 系数 ROM 在核内 | 系数不在核内 |
| READOUT | max-log 24 bit | 末级 | 末级 |

工作方式学 1BOX：流式、连续处理、第一轮用复位送 β=0，避免擦存储器。一轮拍数

`D = L_A2 + L_SORT + L_LAM + L_A13 + L_DAMP + L_A5`

（去掉 MVM 时 `L_A2` 等改为外部 `mvm_valid` 到达，**不计入核内动态**）。三轮总拍 `3D`。吞吐

`Θ = 24 · f / (3D)`  bit/s

必须能和将来 Table I 的 Latency 代回。1BOX 公式 (21) 写成 `|X|`、表按 `log2|X|`——这边直接用 24 bit，避免再抄错。

复制 N 份提高吞吐、效率不变：1BOX 的策略，本任务不是第一优先。

## B. 架构细节（一块一段，学 §IV-B）

**1) CTRL**  
存 `iteration`（U2，0..3 含完成）、`stage`。第一轮拉高 β 寄存器复位，使 A2 输入低 180 为 0、高 36 为 `local`。最后一轮才允许下一帧 `H`/分组写入（1BOX H-MEM 的 WE 时机）。

**2) MVM-A2 / A13 / A5**  
不要用 1BOX 那种 U 个复数乘法器加树（那是稠密内积）。本包非零很少：A2 900、A13 828、A5 216。按 **行到达、乘加进累加器**（1BOX MVM2 的顺序，不是 MATLAB 的一次 `x*A`）。系数：4 bit 索引 + 零 mask（表 03–04），或 S18.14。累加 S45.26，输出右移 14 到 S24.12。  
和算法不一致处单写：MATLAB 是整行一次乘；硅上按非零项流过，**只在一行的扇入到齐后**才吐该行（类似 MVM2 最后 W 拍才有效）。

**3) NRM+SORT**  
20 个 9 点稳定降序，并列或复用。结转规则与 MATLAB `sort(...,'descend')` 相同：值相同保留原候选下标。比较在 S32.12（表 23），回写排序域仍 S24.12 并计饱和。延迟 `L_SORT` 待定；v1 组合排序把关键路径拉到 15 ns，v2 **必须拆拍**。

**4) STAT+LAMBDA**  
这是和 1BOX FTF 同类的「非线性、拆不掉」。mix 与 Mills 比一样会 0/0、下溢。**先改 MATLAB**（减峰值已有；再加 LUT 与饱和阈值，用 BER 收口），再画 LUT 深度。未做 LUT 之前不得把 FP32 软核写进能效表冒充已定点。

**5) UNSORT+DAMP**  
`raw(idx)=score`；减最大；`beta=(1-r)*beta+r*raw`，`r` 量化后用 `65536-r` 保证和为 1（表 25）。禁止把 0.3 直接当 DSP 常系数而不定量化误差。

注（1BOX 注 4）：乘法进 DSP48 或 ASIC 乘加时输入输出打拍；关键路径在图上标红。预期候选：SORT 比较链，或 LAMBDA 的 exp 通路，而不是稀疏 MAC（扇入只有 5–6）。

## C. 时序安排（甘特，学 Figure 5）

横轴时钟，纵轴模块。一格写 `(口 p, 候选 ℓ)` 或 `(天线 rx, 变量 v)`。

```
时间 →
MVM-A2     [ 216 入流过，L_A2 后 180 出 ]
NRM+SORT   [          L_SORT ]
LAMBDA     [                 L_LAM  8×4 mix ]
MVM-A13    [                      468 入 … 最后才吐 180 ]
DAMP       [                            L_DAMP ]
MVM-A5     [                                 216 入 → 36 ]
CTRL       [ 3 轮；第 3 轮末 readout ]
```

去掉 MVM：A2/A13/A5 三行改成 `request` 高、等 `valid`，甘特仍画，功耗窗口不含这些空拍。
