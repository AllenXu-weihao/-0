# FPGA 硬件映射与时序推演

2026-11-05。图：[硬件映射与时序](09_FPGA硬件映射与时序推演.html)

**历史设计的读法。** 本文重建实验 2 六段格式的功能映射与操作发射槽。现行系统分区、实装 RTL、候选微架构和 40 MHz 整链验收预算见[论文 11 第三、五节](11_四流64QAM迭代检测器定点化论文梗概.md)。前端、三组 MVM 与统计/残差服务均计入整链；当前反馈控制器承担减峰、排序、散回、阻尼和软读出。下表给的是各服务的算法工作量。依据是 `MIMO.m` 的计算顺序、`deployment.mat` 的矩阵形状，以及实验 2 整机采用的格式：F S14.10、I1 S10.6、I2 S10.6、I3 S16.10、I4 S16.10、R S8.4。80 帧、种子 1105 上这组格式的误码是 243，分档 177 / 61 / 5 / 0。双精度同一批是 256，分档 190 / 61 / 5 / 0。

下面按所列资源与阶段顺序估算已知发射槽：约定 1 次实数乘法或 1 次比较交换占 1 个发射槽，累加器可以每拍收一项。log、exp、4×4 求解内部没有填拍数。该估算未计接口等待、舍入流水尾或访存冲突。最终时钟与能耗需由所选实现的报告及活动测量给出。

## 数据流接到哪一块

一帧先做完 F，再把 I1→I2→I3→I4 走 3 轮，最后只用第 3 轮的 z 做 R。β 在 I3 写回，下一轮 I1 再读。非末轮的 z 不回到计算。

| 段 | 硬件块 | 写出格式 | 下一块怎么接 |
|---|---|---|---|
| F | 锁存、Gram、4×4 求解岛、64 点候选、接收分组 | 寄存器 S14.10 | local 活过整帧。星座坐标仍按精确电平参加统计 |
| I1 | A2 稀疏乘加、减峰、20 口稳定排序 | S10.6，索引 U4 | 排序后的 α 进入 I2 |
| I2 | softmax、均值、方差、残差、mix、20 个 logsumexp | S10.6 | 288 个 λ 与 180 个 ai 逻辑槽拼为 A13 输入；其中 20 个 ai 槽有非零权重 |
| I3 | A13 稀疏乘加、按索引散回、阻尼 | S16.10 | 新 β 同时给 A5 和下一轮 A2 |
| I4 | A5 稀疏乘加 | S16.10 | 只有第 3 轮的 36 个 z 进入 R |
| R | 6 比特两侧取最大、相减、限幅 | S8.4 | 24 个 LLR。硬判是 LLR < 0 |

段和段的位宽不一样，交接处要单独处理：

- β 是 S16.10，进 A2 时再量化到 S10.6。这一步变窄，会再舍入。
- local 是 S14.10。进 A2 时量化到 S10.6；进 A5 时 S14.10 的小数步长和 S16.10 相同，数值可以原样放宽。
- λ 和 ai 是 S10.6，进 A13 时放到 S16.10。S10.6 的每一个可表示值都落在 S16.10 的格点上，范围也更宽，这一步不再增加舍入。
- 当前部署里六个 scale 和温度都是 1，前端残差权重是 0.25，方差缩放是 0.5。1 是连线，0.25 和 0.5 在二进制小数里是移位。ε=0.05 只出现在 log(ε) 和 log(1−ε) 两个常数里。

求解岛吃进去的 Gram、右端和吐出来的中心、协方差是 S14.10，岛内部仍按双精度做 4×4 分解。log 和 exp 也一样：mix、softmax、logsumexp 的三个边界数是 S10.6，边界里面的 log/exp 仍按双精度。这两处换算成 FP32 或 LUT 之前，要另做一次对照。

## 存储单元

容量是有效载荷。没有把 BRAM 端口、对齐和副本算进去，所以不是器件报告。

### 系数 ROM

矩阵按列压缩：每个非零存舍入后的级值或 4 位索引、加上行地址；每列一个起始指针，列数再加 1 个哨兵。零用单独的支撑掩码，不占码本的一级。权重量化到段格式之后，A2 仍是 15 个不同级，A13 仍是 14 个，A5 仍是 13 个，级数没有并掉，也没有饱和。因此 4 位索引加上一张小表，和实验里直接量化权重是同一组数。

| 矩阵 | 形状 | 非零 | 列扇入 | 值加行地址 | 索引加行地址加小表 |
|---|---|---:|---|---:|---:|
| A2 | 216×180 | 900 | 每列恰好 5 | 18010 bit | 12760 bit |
| A13 | 468×180 | 828 | 4 / 5 / 6 的列数是 108 / 36 / 36 | 22510 bit | 12798 bit |
| A5 | 216×36 | 216 | 每列恰好 6，每个输入只用一次 | 5480 bit | 3096 bit |
| 合计 |  | 1944 |  | 46000 bit | 28654 bit |

行地址：A2 和 A5 是 U8，A13 是 U9。列指针位宽按非零个数加 1 取上界，A2 和 A13 是 10 位，A5 是 8 位。以前按 S18.14 存值的稀疏载荷是 55288 bit。表中 46,000 和 28,654 bit 采用 A5 可容纳 216 项的 8 位指针。现有 ROM 生成器统一输出 10 位指针，旧核也把 A5 指针声明为 10 位，37 个指针多 74 个逻辑位；按其声明宽度直接存值应计 46,074 bit。是否物理节省仍须核对综合报告。 [ROM 导出器](../../../MIMO_v2_FPGA/rtl/gen_rom.py)。蓝图改成段格式之后，值本身变窄，地址仍占同样的位。

A2、A5 的非零不跨候选号：输出的第 ℓ 个候选只加第 ℓ 个候选的输入。A13 的 λ 部分也不跨候选，288 个 λ 每个只用一次。跨候选的是 ai：20 个 logsumexp 各连到同组另外 3 个变量的全部 9 个候选，共 540 条。其余 160 个 ai 槽没有权重，不建寄存器。

### 帧内状态

屏障调度下 β 只要一份：A2 读完之后，阻尼才写回。帧和帧重叠时，y、H、候选、标签、local 要做两份，因为下一帧的前端会在本帧 3 轮还没结束时开始写。

| 对象 | 形状 | 格式 | 一份 |
|---|---|---|---:|
| y | 8 路复数 | 实部虚部各 S14.10 | 224 bit |
| H | 8×4 复数 | 实部虚部各 S14.10 | 896 bit |
| nv、iv | 2 个实数 | S14.10 | 28 bit |
| 接收置换 | 8 | U3 | 24 bit |
| 候选序号 | 4×9 | U6 | 216 bit |
| 比特标签 | 4×9×6 | U1 | 216 bit |
| local | 36 | S14.10 | 504 bit |
| β | 180 | S16.10 | 2880 bit |
| 排序索引 | 20×9 | U4，范围 0..8 | 720 bit |
| 合计 |  |  | 5708 bit |

星座不收进 S10.6。64 个符号的 I/Q 电平是 −7…7 的 Gray 表，公共系数是 1/√42。表用两个 4 位有符号数，共 512 bit，系数单独保存。实验里候选坐标以双精度进入均值；硬件在统计单元内部保持这个语义，写出的均值和方差才是 S10.6。

分组不是常数 ROM。每帧按置换后的 H 做一次：先在 8 根接收里选一个三元组，再在剩下的里面选一个二元组，余下三根各自成组。端口号 = 组号×4 + 变量号，共 20 口。组的个数和每组 4 个变量是固定的，成员每帧变。

## 计算单元

| 单元 | 每帧或每轮做多少 | 数据格式 |
|---|---|---|
| 锁存 | 每帧一次 | y、H、两个方差进 S14.10 |
| Gram / 右端 | 实乘 256 + 128。下三角用共轭，不再乘一遍 | 入口 S14.10 |
| 求解岛 | 4×4 厄米分解，5 个右端：1 个估计和 4 列单位阵 | 内部双精度，出口 S14.10 |
| 候选引擎 | 4 变量 × 64 点。实乘约 12288，标量 mix 2048 次。覆盖检查最多 6 遍 | 分数 S14.10，选出的 9 点写成 local |
| 分组 | 21 个三元组代价，再加 10 个二元组代价 | 只产索引 |
| A2 | 每轮 900 次实乘加。9 个候选通道互不相连，每通道 100 次 | 输入、权重、每一项乘积、每一次部分和都回到 S10.6 |
| 排序 | 20 口、每口 9 点稳定降序。20 套插入排序最多 36 次交换；一套比较器则是 720 次 | 值 S10.6，索引 U4。相等时保留原候选下标 |
| 统计 | 每轮 180 次 exp，均值和方差 720 次实乘 | 写出 S10.6。exp 内部仍是双精度 |
| 残差 | 每轮实乘 1376（点积按每个接收天线算一次）。代码在变量循环里重算了 4 遍；数相同，硬件算一次 | 残差和加权能量写出 S10.6 |
| mix | 每轮 288 个标量。每个 2 次 exp 和 1 次 log。log(π(nv+extra)) 只依赖 32 个方差，可以每组算一次。另有 \|r\|² 的 576 次实乘 | 两个对数分量和输出是 S10.6 |
| logsumexp | 每轮 20 个，各对 9 项 | 只保留这 20 个数，S10.6 |
| A13 | 每轮 828 次实乘加。λ 通道不跨候选；ai 的 540 条要加进其他候选 | 乘积和部分和每步回到 S16.10 |
| 反排序 + 阻尼 | 180 个地址散写。阻尼是 307/1024 与 717/1024 各乘一次 | 两项乘积先回到 S16.10，和再回到 S16.10 |
| A5 | 每轮 216 次。9 个通道各 24 次，每个输入只进一个输出 | S16.10 |
| 读出 | 末轮 4 变量 × 6 比特，各做两次 9 点取最大再相减 | 先夹到 ±20，再量化到 S8.4 |

补码 S(8,4) 的范围是 [−8, 7.9375]，步长 1/16。超出相应端点的正负 LLR 被饱和；零附近的负 LLR 可能舍入为零，使 <0 硬判翻转。缺组分支要另测 RTL 的 ±127 输出原码。

A2 / A13 / A5 的乘加和实验是同一种算术：双精度乘完，马上量化到该段格式，加进部分和，部分和也马上量化。A2 上这个格式是 S10.6，A13 和 A5 是 S16.10。宽累加器（乘积保留全部小数位，一列结束才舍入一次）是另一套电路，243 次误码不是在那套电路上得到的。

阻尼系数的分母是 2^10，因为 I3 的小数位是 10。0.3 量化到 S16.10 是 307/1024，补系数 717/1024，两者之和是 1。这和实验里先量化 rate、再在双精度里做 1−rate 的结果一致。

## 时序

依赖是一条链：A2 → 排序 → 统计 → 残差和 mix → A13 → 阻尼。A5 读取的新 β 与下一轮 A2 需要的 β 相同；在两服务独立、存储读端口与接口带宽足够的候选模型中可以重叠。第 3 轮没有下一轮 A2，读出要等本轮 A5。

一轮里、并且算在关键路径上的发射槽，按一块残差乘法器和一块 A2、一块 A13：

| 块 | 发射槽 | 说明 |
|---|---:|---|
| A2 | 900 | 一块乘加器。9 路候选通道同时开时是 100 |
| 排序 | 36 | 20 口各一套插入排序 |
| 统计乘 | 720 | exp 的延迟另计，可能把这块拉长 |
| 残差乘 | 1376 | 点积已按天线复用 |
| mix 的 \|r\|² | 576 | mix 自带乘法器时，大部分能叠在残差乘后面 |
| A13 | 828 | ai 跨候选，不能拆成 9 条互不通信的通道。180 个累加器同时开时，下界是最大扇入 6 |
| 阻尼 | 360 | 一块乘法器串行做旧支路和新支路。两块则是 180 |
| 合计 | 4796 | 含比较槽。不含 log/exp 延迟，不含求解岛 |

三轮是 3×4796 = 14388。末轮 A5 的 216 槽等在读出前面。前两轮的 A5 各 216 槽叠在下一轮 A2 的 900 槽里面。

前端每帧一次，实乘约 13440。其中候选循环的 H(:,v)·c 是 8192，2048 次 mix 里的 \|r\|² 是 4096，Gram、右端、回代和距离合计 1152。2048 次 mix 的 log/exp 另计。求解岛的运算是几十次量级，不放进这 13440。

一帧、前端不与上一帧重叠、A5 按上面的方式重叠时，已知发射槽是 13440 + 14388 + 216 = 28044。全程只有一块乘法器、A5 不能重叠时，再加前两轮 A5 的 432，成为 28476。三块矩阵乘加器分开，缩短的是这 432 个槽，以及下一帧前端能否挨着本帧的核一起跑。一轮内部 A2 和 A13 中间隔着残差，拆开这三块不会把 4796 切掉一大半。

帧启动间隔记为 N 拍。其中

`N = N_front + 3·(4796 + L_exp + L_mix) + 216 + L_read − N_hide`

L_exp、L_mix、L_read 是非线性和读出还没确定的拍数。N_hide 是下一帧前端与本帧核重叠的拍数，不重叠时为 0。吞吐是 24·f / N bit/s。这里的 f 与各 L 是历史模型参数。现行 v0.1 的 40 MHz、48,000 拍/向量是整链建议预算；需要用服务延迟和握手波形分别验证实际延迟与持续启动间隔。

**如何对照现有控制器。** 本图以每轮保留 A5 的参考算法排工作量，三轮矩阵部分共 5,832 项；现有控制器仅末轮发起 A5，对应 5,400 项。现有 RTL 的 `core_cycles` 只记录计算状态的忙拍，论文从状态机推得单次 2,823 忙拍，需由波形复核。28,044 是上面历史资源模型的部分发射槽估算，端到端计时应另加非线性、数据传送、等待、流水排空及读出，重叠按同一时轴只计一次。[现行边界与算术](09_边界与算术锁定.md) · [首版原型验收规格](14_首版原型BER吞吐与延迟规格.md)
