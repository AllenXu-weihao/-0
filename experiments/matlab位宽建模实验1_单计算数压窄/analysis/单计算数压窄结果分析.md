点开 F、I1、I2、I3、I4、R，看每个数单独收到哪一档。绿色是严格 clean 并且短于本梯子最上档。黄色是 clean 停在最上档。红色是最上档已经翻硬判。蓝色的 `ai` 硬判始终对齐，饱和落在 A13 不读的槽上。

严格 clean：硬判差为 0，并且该边饱和为 0。硬判差比的是本档 0/1 和 float 的 0/1。饱和是这个数被夹到端点的次数。候选误码比的是发射真值，不能代替硬判差。协同压窄一节是由单边结果推出的预期，协同实验还没有跑。

## 实验方案：和这次实际操作一致

这次没有另写一套没执行的流程。下面每一步都对应已经跑过的 MATLAB。

共同条件：`make_cases(20,1105)` 只生成一次。背景 SNR 0/10/20/30 dB 各 20 帧。归一化瑞利信道，64-QAM，脉冲概率 0.05，额外方差为背景的 25 倍。输入里的 H 同时当作已知信道。量化器是有符号、MATLAB `round`（.5 远离零）、饱和、实部虚部分开。每档都重算 float 和 `fixed_mvm`，并从原始 y、H 重跑前端和 3 轮反馈。没有 BER/BLER 阈值。乘积或累加被打开时，该矩阵改成按列、按非零行号累加，只有被打开的那一级真正量化。

### 步骤 A · 同一批帧

- **实验目的：** 把后面每一个数放在同一组输入上，差只来自被改的那个数。
- **观察：** float 对真值的误码是 256，其中 0/10/20/30 dB 为 190/61/5/0。`fixed_mvm` 是 254，少的 2 bit 在 0 dB。
- **结论：** 0 dB 上双精度自己就错了 190/480 bit。这一档上几个比特的硬判差，是很差工作点上的判决挪动。
- **所属计算过程：** 整帧。F 一次，I1–I4 重复 3 轮，R 只在末轮。
- **协同压窄预期：** 以后每一段一起压时继续用这 80 帧。30 dB 的 float 误码是 0，协同只要在 30 dB 出现硬判差就停止下探。

### 步骤 B · A2 输出冒烟，不属于阶梯

- **实验目的：** 先看 A2 输出在 S24.12、S22.12、S20.12、S20.10 上动不动。这四档是另一次运行。
- **观察：** S24.12、S22.12、S20.12 硬判差 0、饱和 0。S20.10 硬判差 7，全在 0 dB。
- **结论：** 冒烟说明 A2 输出在 S20.12 这 80 帧上仍 clean。它不写入阶梯的 clean 列。阶梯从 S24.12 跳到 S16.10，中间档没有测。
- **所属计算过程：** I1 先验与排序，数是 `A2_out`。
- **协同压窄预期：** I1 一起压时，A2 输出的起点用阶梯的 S24.12。若要把冒烟的 S20.12 收进协同，先单独再确认一档，不从阶梯表里直接取。

### 步骤 C · 46 个数的阶梯

- **实验目的：** 每个数单独离开 double，找到严格 clean 的最窄已测档，并记下再窄一档的硬判差和饱和。
- **观察：** 294 行在 `result/阶梯汇总/width_push_20261105/summary.csv`。6 行是 ERROR：`input_nv` 的 S10.8、S8.6、S6.4，`input_iv` 的 S10.4、S8.2、S6.2。生成观察稿时把 ERROR 丢掉了，曾写成「最窄档仍未翻转」，这个说法作废。
- **结论：** 21 个数短于本梯子最上档并且 clean。20 个数的 clean 停在最上档。4 个数在最上档已经翻硬判：`input_H` 和三个 mix。`ai` 单独计。位宽不单调，`A2_x` 在 S6.3 硬判差 113、S4.2 为 97；`frontend_cov` 在 S16.8 硬判差 2、LLR 差 18.97，S12.6 硬判差 16、饱和 0、LLR 差 0.496。下一轮不用二分。
- **所属计算过程：** 每个数的过程写在下面各节。全宽有序乘加相对 double 的最大 LLR 差：A2 为 3.81×10⁻⁸，A13 为 4.38×10⁻⁸，A5 为 5.39×10⁻⁸。
- **协同压窄预期：** 一段内部只叠该段的 clean 档，其余段保持 double。硬判差为 0 但仍饱和的档不进起点。预期写在每段末尾，还不是测量。

消息梯子是 S24.12、S16.10、S12.8、S10.6、S8.4、S6.3、S4.2。权重梯子从 S18.14 起。乘积从 S42.26 起，累加从 S45.26 起。各数用的梯子写在该数的目的里。

## F 候选准备

这段锁存 H、y 和两个方差，做 Gram 与右端，解 4×4，给 4×64 个星座点打分，写出 local。分解和除法保持 double。H、y、候选和 local 活过整帧。

### `frontend_rhs`

- **实验目的：** 只量化 Hᴴy。梯子 S24.12、S16.8、S12.6、S10.4、S8.2。
- **观察：** 严格 clean 收到 S16.8，最大 LLR 差 0.736。S12.6 硬判差 30/0/0/0，饱和 0。
- **结论：** 右端可以离开 S24.12，再窄一档会在 0 dB 翻 30 bit。
- **所属计算过程：** F。它是求解的右端，和 Gram 一起进 `A\b`，求解内部仍是 double。
- **协同压窄预期：** F 一起压时它可以从 S24.12 收到 S16.8。和 Gram、中心叠在同一条分数上之后，预期 0 dB 先出现硬判差；这一数本身不是 H 那种「最上档已经翻」的限制。

### `frontend_variance`

- **实验目的：** 只量化协方差对角线。梯子 S24.16、S16.12、S12.10、S10.8、S8.6。
- **观察：** 严格 clean 收到 S16.12，最大 LLR 差 0.157。S12.10 硬判差 1/0/0/0，饱和 9。
- **结论：** 评分用的方差可以收到 S16.12。再窄就开始夹，并在 0 dB 翻 1 bit。
- **所属计算过程：** F。它来自协方差对角，供 64 点评分，不进入核内三轮。
- **协同压窄预期：** 和分数、local 一起压时，S16.12 是起点。再收到 S12.10 会把饱和带进候选排序，预期候选集合在 0 dB 先变。

### `input_nv`

- **实验目的：** 只量化背景噪声方差。梯子 S16.14、S12.10、S10.8、S8.6、S6.4。
- **观察：** S12.10 硬判差 0、饱和 0，最大 LLR 差 2.291。S10.8 及更窄是 ERROR，量化后方差不再为正，没有判决。
- **结论：** clean 停在 S12.10。更窄不是「未翻转」，是计算中断。LLR 在 clean 档已经移动 2.29，判决还没动。
- **所属计算过程：** F。它进入 Gram 的对角加载，也进入 I2 的 mix。本步只在输入口量化，mix 内部仍是 double。
- **协同压窄预期：** F 或 I2 一起压时都不得窄于 S12.10。再窄预期不是多几个硬判差，而是整帧失败。

### `input_iv`

- **实验目的：** 只量化脉冲额外方差。梯子 S16.8、S12.6、S10.4、S8.2、S6.2。
- **观察：** S16.8 和 S12.6 最大 LLR 差都是 0，硬判差 0，饱和 0。S10.4 及更窄 ERROR。
- **结论：** 这 80 帧上 S12.6 仍和 double 的 LLR 一致。再窄中断。
- **所属计算过程：** F 的输入，供 I2 的脉冲分量。本步没有改 mix 的字长。
- **协同压窄预期：** 和 mix 一起压之前，iv 停在 S12.6。mix 自己在 8 个小数位上已经翻判决，iv 的 clean 盖不住 mix 的小数位。

### `input_y`

- **实验目的：** 只量化 8 路接收。消息梯子，从 S24.12 跳到 S16.10。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.807，饱和 0。S16.10 硬判差 3/0/0/0，饱和 0。
- **结论：** 规格 S24.12 还没翻判决，LLR 已经移动约 0.8。没有测到更短的 clean 档。
- **所属计算过程：** F。y 锁存整帧，后面残差也读它。本步量化的是帧首的 y。
- **协同压窄预期：** F 一起压时 y 留在 S24.12。它和 Gram、H 走同一条候选分数。H 已经在 S24.12 翻了 5 bit，所以 F 的协同限制先是 H，不是把 y 再收到 S16.10。

### `frontend_gram`

- **实验目的：** 只量化 HᴴH + nv I。梯子 S24.12、S16.8、S12.6、S10.4、S8.2。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.806。S16.8 硬判差 13/1/0/0，饱和 0。
- **结论：** Gram 在 S16.8 已经伤到 10 dB 的 1 bit。候选会跟着变，后面三轮在新的 9 个点上转。
- **所属计算过程：** F 的 K2 复乘归约。求解内部仍是 double。
- **协同压窄预期：** F 一起压时 Gram 留在 S24.12。若和右端的 S16.8 同时收，预期 0 dB 的硬判差会多于右端单独的 30 bit 或 Gram 单独再窄时的 13 bit，10 dB 也可能出现，因为 Gram 单独的下一档已经碰到 10 dB。

### `frontend_center`

- **实验目的：** 只量化求解得到的中心。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.079。S16.10 硬判差 9/0/0/0，饱和 0。
- **结论：** 中心在 S24.12 上 LLR 移动不大，跳到 S16.10 就在 0 dB 翻 9 bit。
- **所属计算过程：** F。它是 `A\b` 的输出，供评分，不进核内消息。
- **协同压窄预期：** 和 Gram、右端一起压时，中心留在 S24.12。Gram 的量化误差会先进入这个数，所以协同后的中心即使字长仍是 S24.12，也不再是「只量化中心」的那一档。

### `frontend_cov`

- **实验目的：** 只量化协方差。梯子同 Gram。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.157，饱和 0。S16.8：硬判差 2，饱和 0，最大 LLR 差 18.97，2 bit 在 0 dB。S12.6：硬判差 16，饱和 0，最大 LLR 差 0.496，16 bit 全在 0 dB。
- **结论：** 两档都没有饱和。更窄以后翻开的判决变多，单点最大 LLR 差变小。不能用二分搜索。
- **所属计算过程：** F。协方差供评分方差，不进三轮消息。
- **协同压窄预期：** 起点 S24.12。若 F 段把 Gram 和协方差一起收到 S16.8，预期同时看到「硬判差变多」和「个别 LLR 被推到接近限幅」，两个现象不必同向。

### `frontend_score`

- **实验目的：** 只量化 64 点评分。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.087。S16.10 硬判差 2/0/0/0，饱和 2942。
- **结论：** 跳到 S16.10 时判决只在 0 dB 差 2 bit，分数已经被大量夹住。严格 clean 仍是 S24.12。
- **所属计算过程：** F 的 K5。Top9 和覆盖读这个分数，候选集合一变，核内三轮的 9 个点都变。
- **协同压窄预期：** 分数留在 S24.12。它和 local 决定候选。协同时若只看硬判差、忽略 2942 次饱和，会把一组已经夹过的分数送去选点。

### `frontend_local`

- **实验目的：** 只量化候选局部项。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.0006。S16.10 硬判差 1/0/0/0，饱和 2。
- **结论：** S24.12 几乎不动 LLR。S16.10 开始有饱和，并在 0 dB 翻 1 bit。
- **所属计算过程：** F 写出，I1 和 I4 的 A2、A5 每轮读它。本步量化的是帧首那一份。
- **协同压窄预期：** F 一起压时留在 S24.12。I1 协同时不要把 local 再量化第二次；本实验的 local 量化只发生在 F。

### `input_H`

- **实验目的：** 只量化 8×4 信道。消息梯子，最上档就是规格 S24.12。
- **观察：** S24.12 硬判差 5，全在 0 dB，饱和 0，最大 LLR 差 0.793。
- **结论：** 规格位宽本身就翻了判决。饱和为 0，差在小数位，不是装不下。这条梯子没有 clean 档。
- **所属计算过程：** F。H 同时被 Gram、右端、I2 残差使用。本步只量化输入口。
- **协同压窄预期：** F 一起压时 H 先留在 double。若把 S24.12 放进协同，预期至少带入这 5 bit。先单边补 S28.16、S24.16、S24.14，出现 clean 之后 H 才进入 F 的协同。

**F 段一起压的预期：** 用各数的 clean 档、H 保持 double 时，Gram、y、中心、协方差、分数、local 都已经停在 S24.12，余量只在右端 S16.8 和方差 S16.12。预期硬判差首先在 0 dB，Gram 的下一档已经碰到 10 dB，所以 10 dB 不能事先排除。求解器内部仍是 double，这段协同加的是矩阵口和分数的量化，不是分解算法的误差。

## I1 先验与排序

旧 β 和 local 进 A2，20 口 × 9 候选，减峰后成为 α，再稳定降序。9 条车道在矩阵里不相交。索引留到本轮反排。

### `A2_w`

- **实验目的：** 只量化 A2 权重。梯子 S18.14、S14.12、S12.10、S10.8、S8.6、S6.4、S4.2。
- **观察：** S18.14 最大 LLR 差 9.52×10⁻⁵。严格 clean 收到 S12.10，最大 LLR 差 0.082。S10.8 硬判差 5/0/0/0，饱和 0。
- **结论：** 系数可以从规格 S18.14 收到 S12.10，再窄在 0 dB 翻 5 bit。S18.14 的 LLR 差和码本量化同一量级。
- **所属计算过程：** I1 的 K1。列扇入恒为 5，不读本口自己的 β。
- **协同压窄预期：** I1 一起压时权重用 S12.10。消息口停在 S24.12，权重不是第一限制。和输入、输出叠在一起后，预期仍先在 0 dB 翻，不会先在 10 dB 翻，因为权重的下一档 5 bit 全在 0 dB。

### `A2_product`

- **实验目的：** 只量化按列非零乘积。梯子 S42.26、S32.20、S24.14、S20.12、S16.10、S12.8、S8.4。
- **观察：** S42.26 最大 LLR 差 3.81×10⁻⁸。严格 clean 收到 S20.12，最大 LLR 差 0.017。S16.10 硬判差 8/0/0/0，饱和 23。
- **结论：** 这 80 帧上乘积可以从 S42.26 收到 S20.12。全宽时求和顺序的影响在 10⁻⁸。这是 double 算完再量化。
- **所属计算过程：** I1。每个非零乘积量化一次，再送进累加。
- **协同压窄预期：** 和权重、累加一起压时用 S20.12。整数 MAC 的保护位还没测，预期不能写成 RTL 的 20 位乘积。

### `A2_acc`

- **实验目的：** 只量化按列运行的累加。梯子从 S45.26 到 S8.4，中间有 S32.18、S24.14、S20.12、S16.10、S12.8。
- **观察：** S45.26 的 LLR 差与乘积全宽相同，3.81×10⁻⁸。clean 收到 S20.12。S16.10 硬判差 8/0/0/0，饱和 8055。
- **结论：** 判决边界和乘积的 S16.10 一样是 8 bit，饱和次数高一个数量级。clean 是 S20.12。
- **所属计算过程：** I1。扇入 5，累加在 double 中逐项量化。
- **协同压窄预期：** 与乘积同时放在 S20.12 时，两项误差叠在同一列和上，预期 0 dB 的硬判差大于单独任何一项的 0。不要用 S16.10，那一档单独就已经饱和八千次。

### `A2_x`

- **实验目的：** 只量化 A2 的输入，旧 β 和 local。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.037。S16.10 硬判差 3/0/0/0，饱和 6，候选误码 253。更窄处不单调：S6.3 硬判差 113，S4.2 硬判差 97。
- **结论：** S16.10 的 3 bit 是相对 float 的算法改写；候选对真值少错 3 bit，不能当成位宽更优。更窄不一定更差，禁止二分。
- **所属计算过程：** I1 的矩阵输入。local 若已在 F 量化，这里是第二次量化；本步 F 仍是 double，所以只量化这一次。
- **协同压窄预期：** I1 起点用 S24.12。它和 α、输出同为消息口，三者都停在 S24.12，叠在一起预期先在 0 dB 出现硬判差。

### `alpha`

- **实验目的：** 只量化减峰后的 20×9 先验。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.101。S16.10 硬判差 3/0/0/0，饱和 4712。
- **结论：** S24.12 已经把 LLR 移动约 0.1，判决未动。S16.10 大量饱和。
- **所属计算过程：** I1 写出，I2 的 exp 读排序后的 α。
- **协同压窄预期：** I1 留在 S24.12。I2 不要把 α 再量化一次。若 I1 协同把 A2 输出和 α 都放在 S24.12，α 上的 0.1 LLR 差会进入 I2 的指数，预期 I2 看见的先验已经不是 double。

### `A2_out`

- **实验目的：** 阶梯只量化 A2 输出，消息梯子，不含 S22.12 和 S20.12。
- **观察：** 阶梯 clean 是 S24.12，最大 LLR 差 0.017。下一档 S16.10 硬判差 7/0/0/0，饱和 4774。冒烟另见步骤 B。
- **结论：** 阶梯没有证明 S20.12。冒烟里的 S20.12 单独存放。
- **所属计算过程：** I1。输出减峰后写成 α。
- **协同压窄预期：** I1 起点用阶梯的 S24.12。冒烟的 S20.12 若要进入协同，先单独再跑一档。和权重 S12.10、乘积 S20.12 一起压时，限制在输出和输入，不在权重。

**I1 一起压的预期：** 权重 S12.10，乘积和累加 S20.12，输入、α、输出 S24.12，其余段保持 double。预期硬判差出现在 0 dB，个数多于任何单边 clean 档上的 0。10 dB 和 20 dB 在这些下一档里都没有出现，协同后仍要分桶核对，不能事先当成不会出现。排序索引保持精确，不量化。

## I2 统计与证据

排序后的 α 做 exp、求和、概率、均值和方差，再算残差和加权能量，mix 写出 λ。ai 的第 1 列是 logsumexp。

### `exp`

- **实验目的：** 只量化减峰后的指数。梯子 S16.14、S10.8、S8.6、S6.4、S4.2。
- **观察：** clean 收到 S8.6，最大 LLR 差 0.344。S6.4 硬判差 8/0/0/0，饱和 0。
- **结论：** 指数可以收到 S8.6，再窄只在 0 dB 翻 8 bit。
- **所属计算过程：** I2 链的第一级，后面是九路求和。
- **协同压窄预期：** 和分母、概率一起压时用 S8.6。这三级的舍入会进均值，预期 0 dB 硬判差大于 exp 单独的 0。S6.4 的 8 bit 全在 0 dB，协同后若 10 dB 出现硬判差，先看方差和加权能量，不是先看 exp。

### `sum_exp`

- **实验目的：** 只量化一口 9 路指数和。梯子 S16.11、S12.7、S10.5、S8.4、S6.2。
- **观察：** clean 收到 S10.5，最大 LLR 差 0.754。S8.4 硬判差 1/0/0/0，饱和 2。
- **结论：** 分母可以收到 S10.5。再窄开始饱和，并在 0 dB 翻 1 bit。9 个指数相加，整数位要留得住这个和。
- **所属计算过程：** I2。概率等于指数除以这个分母。
- **协同压窄预期：** 起点 S10.5。和 exp 的 S8.6 一起压时，分母上的舍入会放大成概率误差。预期仍先在 0 dB。

### `prob`

- **实验目的：** 只量化概率。梯子 S16.14、S10.8、S8.6、S6.4、S4.2，中间没有档。
- **观察：** clean 只有最上档 S16.14，最大 LLR 差 0.004。S10.8 硬判差 2/0/0/0，饱和 0。
- **结论：** 不能把没测过的 S12 或 S14 写成 clean。本梯子的起点就是 S16.14。
- **所属计算过程：** I2。均值、方差都由它加权。
- **协同压窄预期：** 用 S16.14。它是链上最宽的 clean 档之一，和更短的 exp、方差叠在一起时，概率字长可能盖住后面的短格式，也可能把 S10.8 那种 2 bit 提前推出来。预期先看 0 dB。

### `mu`

- **实验目的：** 只量化均值。消息梯子，所以有 S16.10 和 S12.8。
- **观察：** clean 收到 S12.8，最大 LLR 差 0.374。S10.6 硬判差 9/0/1/0，饱和 0。
- **结论：** 均值可以收到 S12.8。再窄有 1 bit 在 20 dB。这是中等 SNR 已经会被单独推开的数。
- **所属计算过程：** I2。残差用 y − Hμ，再补回本变量。
- **协同压窄预期：** 起点 S12.8。和方差、加权能量一起压时，若 10 dB 或 20 dB 出现硬判差，先把均值放回 S16.10，因为它的下一档已经碰到 20 dB。

### `var`

- **实验目的：** 只量化方差。梯子 S16.12、S12.10、S10.8、S8.6、S6.4、S4.2。
- **观察：** clean 收到 S8.6，最大 LLR 差 0.886。S6.4 硬判差 10/1/2/0，饱和 0。
- **结论：** 方差是 I2 里最短的 clean 之一，也是再窄就会伤到 10 dB 和 20 dB 的数。
- **所属计算过程：** I2。加权能量读它，mix 的方差项读加权能量。
- **协同压窄预期：** 起点 S8.6。协同后若中等 SNR 翻判决，第一回退就是把它放回 S10.8。

### `weighted`

- **实验目的：** 只量化信道能量乘方差。梯子同方差。
- **观察：** clean 收到 S10.8，最大 LLR 差 0.938。S8.6 硬判差 5/0/1/0，饱和 0。
- **结论：** 比方差少一档余量。下一档有 1 bit 在 20 dB。
- **所属计算过程：** I2，残差的方差项，随后进入 mix。
- **协同压窄预期：** 起点 S10.8。和方差的 S8.6 叠在一起时，加权能量更宽，预期先顶住的是方差的 S8.6，不是把加权能量再收到 S8.6。

### `residual`

- **实验目的：** 只量化复残差。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.101。S16.10 硬判差 1/0/0/0，饱和 0。
- **结论：** 残差没有短于 S24.12 的 clean 档。下一档只在 0 dB 翻 1 bit，饱和为 0，是小数位。
- **所属计算过程：** I2。每个接收天线、每个被更新的变量各算一次，然后送进 mix。
- **协同压窄预期：** 起点 S24.12。它和 λ 是这条链上最宽的 clean。短格式的均值、方差先叠进来之后，残差即使仍写 S24.12，输入已经带量化误差。预期协同的硬判差会大于残差单独的 0。

### `lambda`

- **实验目的：** 只量化 mix 写出的证据。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.027。S16.10 硬判差 1/0/0/0，饱和 3。
- **结论：** 和残差一样，clean 停在最上档。再窄有 3 次饱和。
- **所属计算过程：** I2 的输出，I3 的 A13 输入。本步 I3 仍是 double，所以 λ 只量化一次。
- **协同压窄预期：** I2 起点 S24.12。I3 协同时不要把 λ 再量化；I3 量化的是 `A13_x`。两段各量化一次会把同一条证据剪两次。

### `ai`

- **实验目的：** 只量化整列 ai。消息梯子。
- **观察：** S24.12 硬判差 0、饱和 0，最大 LLR 差约 1.07×10⁻¹⁴。从 S16.10 到 S4.2 硬判差仍是 0，LLR 差不变，饱和从 4711 增到 22092。
- **结论：** 严格 clean 只有 S24.12。更窄的硬判不变，是因为 A13 只读每口第 1 列，其余 160 个数饱和不影响 LLR。不能据此把 logsumexp 收成 4 bit，也不能据此给 180 个数都留数据通路。
- **所属计算过程：** I2 写出第 1 列，I3 的 A13 读取。本步量化的是整列。
- **协同压窄预期：** I2 和 I3 都不要把现有整列插桩放进协同。放进去预期饱和很大、硬判差仍接近 0，会把未连接槽的饱和误当成这段失败。要压 logsumexp，先把插桩改成只量化第 1 列。

### `mix_a`、`mix_b`、`mix_output`

- **实验目的：** 三个数分开量化。梯子都是 S32.8、S24.8、S16.6、S12.4、S8.2。小数位从 8 开始。
- **观察：** S32.8 饱和都是 0。`mix_a` 硬判差 14，最大 LLR 差 0.498。`mix_b` 硬判差 2，最大 LLR 差 0.497。`mix_output` 硬判差 14，最大 LLR 差 0.246。全在 0 dB。S24.8 与 S32.8 的硬判差和 LLR 差相同。
- **结论：** 这组梯子没有 clean 档。整数位从 32 收到 24 不改变结果，8 个小数位决定了这 80 帧。规格位宽这个概念在 mix 上还没有被测到；所测最宽档已经翻判决。
- **所属计算过程：** I2 的 K4。两个对数分量相加写成 λ 之前的 mix。
- **协同压窄预期：** 第一组 I2 协同不包含这三个数，它们保持 double。若现在放进去，预期至少带入 `mix_a` 的 14 bit，统计链的短格式就分不出来了。先单边补小数位 S32.16、S24.16、S24.12、S20.12，出现 clean 再并进 I2 的第二组。

**I2 一起压的预期：** 第一组用 exp S8.6、指数和 S10.5、概率 S16.14、均值 S12.8、方差 S8.6、加权能量 S10.8、残差 S24.12、λ S24.12。mix 和 ai 整列保持 double，其余段保持 double。预期硬判差大于任何单边 clean 档上的 0，先出现在 0 dB。若 10 dB 或 20 dB 出现，按方差、均值、exp、加权能量的顺序，一次只放宽一个数。这条链是串行的，短格式的误差会进残差和 λ，所以「各自 clean」叠在一起后可以离开 clean。

## I3 消息与阻尼

A13 读 λ 和 ai，反排、减峰、缩放得到 raw，再与旧 β 按 rate = 0.3 混合，写完 180 个数后交换 bank。

### `A13_w`

- **实验目的：** 只量化 A13 权重。权重梯子，从 S18.14 起。
- **观察：** clean 收到 S14.12，最大 LLR 差 0.157。S12.10 硬判差 6/0/0/0，饱和 0。
- **结论：** 比 A2 权重少一档。S14.12 的 LLR 差已经到 0.16，判决未动。
- **所属计算过程：** I3 的 K1。ai 区只有每口第 1 列接入，列扇入按组大小是 6/5/4。
- **协同压窄预期：** 起点 S14.12。和 β 的 S24.12 一起压时，权重不是限制项。再收到 S12.10 会在 0 dB 单独翻 6 bit。

### `A13_product` 与 `A13_acc`

- **实验目的：** 分别只量化乘积、只量化累加。乘积梯子从 S42.26 起，累加从 S45.26 起。
- **观察：** 全宽 LLR 差都是 4.38×10⁻⁸。两者 clean 都收到 S20.12，最大 LLR 差 0.157。S16.10 硬判差都是 4/0/0/0，饱和都是 5。
- **结论：** 这一对在 S16.10 的判决和饱和次数相同。clean 是 S20.12。仍是 double 后再量化。
- **所属计算过程：** I3。累加按列的非零项进行，最大扇入 6。
- **协同压窄预期：** 两点都用 S20.12。和输出一起压时，输出的 clean 仍是 S24.12；S16.10 的输出饱和为 5、硬判差为 0，那一档不进起点。

### `rate`

- **实验目的：** 只量化阻尼系数 0.3。梯子 S18.16、S12.10、S8.6、S6.4、S4.2。
- **观察：** S18.16 最大 LLR 差 1.58×10⁻⁴。clean 收到 S12.10，最大 LLR 差 0.151。S8.6 硬判差 9/0/0/0，饱和 0。
- **结论：** 0.3 不是二的幂。S12.10 仍 clean，再窄在 0 dB 翻 9 bit。互补系数要和 rate 一起收成和为 1 的一对，本步只量化了 rate 这个口。
- **所属计算过程：** I3 的 K6。旧支路用 1−rate，新支路用 rate。
- **协同压窄预期：** 起点 S12.10。和两条乘积一起压时，rate 的舍入会同时改变两条支路的比例。预期 0 dB 的硬判差大于 rate 单独的 0。

### `damp_product_old`

- **实验目的：** 只量化 (1−rate)·旧 β。消息梯子。
- **观察：** 严格 clean 收到 S16.10，最大 LLR 差 0.039，饱和 0。S12.8 硬判差 8/0/0/0，饱和 375。
- **结论：** S16.10 是 clean，S12.8 不是。clean 只覆盖测过并且两个计数都为 0 的那一档。
- **所属计算过程：** I3。读的是旧 bank 的 β。
- **协同压窄预期：** 起点 S16.10。β 本身的 clean 仍是 S24.12，所以旧 β 先以 S24.12 存在，再乘到 S16.10。协同后这条支路比单边多一次来自 β 字长的误差。

### `damp_product_new`、`damp_sum`、`beta`

- **实验目的：** 三个数分别量化。都是消息梯子。
- **观察：** 三者 clean 都停在 S24.12，最大 LLR 差约 0.101 到 0.102。S16.10 硬判差都是 4/0/0/0，饱和都是 0。
- **结论：** 新支路、相加、写回在这组帧上同一边界。S16.10 没有饱和，是精度把 0 dB 的 4 bit 推开了。
- **所属计算过程：** I3 的写回。`beta` 是下一轮 I1 的旧消息，双缓冲，180 个数写完才交换。
- **协同压窄预期：** 三个都留在 S24.12。它们和 `damp_product_old` 的 S16.10 一起压时，新支路更宽，预期限制在新支路和 β，不在旧支路。β 是跨轮状态，量化误差会在 3 轮里留下来。

### `A13_x`

- **实验目的：** 只量化 A13 输入。消息梯子。
- **观察：** clean 停在 S24.12，最大 LLR 差 0.027。S16.10 硬判差 1/0/0/0，饱和 4714。
- **结论：** 和 `ai` 一样，大量饱和来自不读取的槽。严格 clean 仍是 S24.12，因为饱和不为 0。
- **所属计算过程：** I3 的入口。λ 若已在 I2 量化，这里是第二次；本步 I2 是 double。
- **协同压窄预期：** I3 起点 S24.12。不要和 I2 的 λ 量化叠成两次。饱和计数要和「被 A13 用到的行」分开，否则协同会被未连接槽判失败。

### `A13_out`

- **实验目的：** 只量化 A13 输出。消息梯子。
- **观察：** clean 是 S24.12，最大 LLR 差 0.101。S16.10 硬判差 0，饱和 5，最大 LLR 差 0.101。第一处硬判差在 S12.8，为 67/11/1/0，饱和 6364。
- **结论：** S16.10 判决未动，但已经饱和，不是 clean。S12.8 把 10 dB 和 20 dB 也推开了。
- **所属计算过程：** I3。输出随后反排、减峰，成为 raw。
- **协同压窄预期：** 起点 S24.12。若协同误用 S16.10，预期饱和会和 raw、β 的量化叠在一起，硬判差不必仍是 0。S12.8 的 67/11/1 是「再往下」的样子，不是起点。

### `raw`

- **实验目的：** 只量化减峰缩放后的新消息。消息梯子。
- **观察：** clean 是 S24.12，最大 LLR 差 0.157。S16.10 硬判差 0，饱和 139，最大 LLR 差 0.097。S12.8 硬判差 2/0/0/0。
- **结论：** 和 A13 输出同类：S16.10 硬判未动，饱和已经出现，严格 clean 停在 S24.12。
- **所属计算过程：** I3。随后乘 rate，与旧支路相加。
- **协同压窄预期：** 起点 S24.12。和 rate 的 S12.10、旧支路的 S16.10 一起压时，raw 是更宽的那一端。预期 0 dB 先动。

**I3 一起压的预期：** 权重 S14.12，乘积和累加 S20.12，rate S12.10，旧支路 S16.10，输入、输出、raw、新支路、和、β 都是 S24.12。ai 整列不进入。预期硬判差在 0 dB，β 把误差留到下一轮，所以三轮结束时的硬判差可以大于第一轮。S16.10 上硬判差为 0 但已饱和的输出和 raw，不放进这组。

## I4 后验

新 β 进 A5，写出 36 个 z。非末轮的 z 不回到下一轮。

### `A5_w`

- **实验目的：** 只量化 A5 权重。权重梯子。
- **观察：** clean 收到 S10.8，最大 LLR 差 0.016。S8.6 硬判差 2/0/0/0，饱和 0。S18.14 的最大 LLR 差是 2.81×10⁻⁴。
- **结论：** 三块矩阵里 A5 权重最短，可以到 S10.8。再窄只在 0 dB 翻 2 bit。
- **所属计算过程：** I4 的 K1。列扇入恒为 6，每个输入只用一次。
- **协同压窄预期：** 起点 S10.8。和输出的 S24.12 一起压时，权重余量大，限制在 z 的字长。不要把权重的短格式当成 z 也可以是 10 位。

### `A5_product`

- **实验目的：** 只量化 A5 乘积。乘积梯子。
- **观察：** 全宽 LLR 差 5.39×10⁻⁸。clean 收到 S20.12，最大 LLR 差 0.0007。S16.10 硬判差 0，饱和 1。第一处硬判差在 S12.8，2/0/0/0。
- **结论：** S16.10 有 1 次饱和，不是严格 clean。clean 是 S20.12。
- **所属计算过程：** I4。乘积随后进入累加。
- **协同压窄预期：** 起点 S20.12。那 1 次饱和若放进协同，预期和累加的大饱和叠在同一列上。

### `A5_acc`

- **实验目的：** 只量化 A5 累加。累加梯子。
- **观察：** 全宽 LLR 差同乘积，5.39×10⁻⁸。clean 收到 S20.12。S16.10 硬判差 0，饱和 4350。S12.8 硬判差 2/3/7/0。
- **结论：** S16.10 判决未动，累加已被夹四千多次，不是 clean。
- **所属计算过程：** I4。扇入 6 的运行和。
- **协同压窄预期：** 起点 S20.12。S12.8 的 10 dB 差 3 bit、20 dB 差 7 bit，与 `A5_out` 同一两帧，另有 0 dB 一帧多 2 bit。协同若离开 S20.12，预期先在这两帧上看到中等 SNR 的硬判差。

### `A5_x`

- **实验目的：** 只量化 A5 输入，即新 β。消息梯子。
- **观察：** clean 是 S24.12，最大 LLR 差 0.0008。S16.10 硬判差 0、饱和 6。S12.8 硬判差 0、饱和 4880。第一处硬判差在 S10.6，10/0/0/0。
- **结论：** 收到 S12.8 判决仍可以不动，饱和已经是几千次。严格 clean 停在 S24.12。
- **所属计算过程：** I4 的入口。β 若已在 I3 量化，这里是第二次；本步 I3 是 double。
- **协同压窄预期：** 起点 S24.12。I3 与 I4 不要对 β 各量化一次。S12.8 的「硬判差为 0」不能当协同起点。

### `A5_out`

- **实验目的：** 只量化 36 个 z。消息梯子。
- **观察：** clean 是 S24.12，最大 LLR 差 0.0002。S16.10 硬判差 0，饱和 1515，最大 LLR 差 0.001。S12.8 硬判差 0/3/7/0。S6.3 在 30 dB 差 3 bit，S4.2 在 30 dB 差 6 bit。
- **结论：** S16.10 不是 clean。S12.8 在 10 dB 和 20 dB 先于 0 dB 翻判决，和累加是相同的两帧。很窄以后 30 dB 也会翻。
- **所属计算过程：** I4 的输出。只有第 3 轮的 z 进入 R。
- **协同压窄预期：** 起点 S24.12。和权重 S10.8、乘积累加 S20.12 一起压时，z 的字长是限制。若误用 S16.10，预期饱和上千，硬判差不必仍是 0，因为累加的饱和会同时进来。

**I4 一起压的预期：** 权重 S10.8，乘积和累加 S20.12，输入和输出 S24.12。预期在 clean 档叠在一起时，LLR 移动仍然小，因为输入和输出单独的 LLR 差都在 10⁻³ 以下；一旦改用 S16.10 的输出或累加，预期饱和主导，并在 S12.8 那个方向上碰到 10 dB 和 20 dB。非末轮 z 不反馈，所以 I4 的量化不改下一轮的 β。末轮 z 会进入 LLR。

## R 软比特

### `llr`

- **实验目的：** 只量化夹到 ±20 之后的 24 个 LLR。消息梯子。
- **观察：** clean 收到 S16.10，最大 LLR 差 0.0005，饱和 0。S12.8 硬判差 2/0/0/0，饱和 1060，最大 LLR 差 12。
- **结论：** 读出可以到 S16.10。S12.8 把 LLR 拉开到 12，硬判只在 0 dB 差 2 bit。限幅是 ±20，12 已经是读出端自己的量化。
- **所属计算过程：** R。末轮 z 按比特标签两侧取最大，相减，再夹紧。这段只有这一个插桩数。
- **协同压窄预期：** 不再单开 R 的协同。I4 的 z 若离开 S24.12，LLR 即使仍写 S16.10，输入已经带量化。预期硬判差由 I4 决定，R 的 S16.10 只再加读出舍入。

## 后续判断时怎么用这份分析

单边 clean 是下一次「一段内部一起压」的起点，不是整机字长。硬判差为 0 但饱和不为 0 的档，包括 `A13_out` 与 `raw` 的 S16.10、`A5_out` 的 S16.10、`A5_x` 的 S12.8，不进起点。`input_nv`、`input_iv` 停在最后一个仍为正的格式。`input_H` 和三个 mix 没有 clean 档。A2 输出的 S20.12 留在冒烟目录。
