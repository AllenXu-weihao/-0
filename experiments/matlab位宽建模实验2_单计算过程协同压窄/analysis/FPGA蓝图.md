# FPGA 位宽蓝图

2026-11-05。数据流图： [数据流图.html](数据流图.html)。硬件块、存储和排拍： [FPGA硬件映射与时序推演](../../../文档/matlab建模文档/09_FPGA硬件映射与时序推演.md)，图： [硬件映射与时序](../../../文档/matlab建模文档/09_FPGA硬件映射与时序推演.html)。

控制变量是一段计算过程。从双精度出发，一段里所有被插桩的数收成同一个有符号格式，其余段保持双精度，前端和 3 轮都重算。同一批 80 帧、种子 1105，共 1920 bit。判据是对发射比特的误码个数：先取误码最少的档，误码相同再取总位宽更窄的档。饱和次数和与 float 的硬判差照实记下，不作为取舍门槛。

双精度误码 256，分档 190 / 61 / 5 / 0。`fixed_mvm` 是 254。

## 每段单独压窄

梯子是 S24.14、S20.12、S18.12、S16.12、S16.10、S14.10、S12.8、S12.6、S10.6、S8.4。F 在 S12.8 及更窄中断，量化后的方差不再为正。

| 过程 | 单独采用 | 误码 | 0/10/20/30 dB | 再往下 |
|---|---|---:|---|---|
| F 候选准备 | S14.10 | 252 | 186/61/5/0 | 中断，没有更窄的结果 |
| I1 先验与排序 | S10.6 | 247 | 181/61/5/0 | S8.4 升到 263，10 dB 降到 59、0 dB 升到 199 |
| I2 统计与证据 | 单独最少是 S8.4，243 次，但 20 dB 为 7 | 243 | 175/61/7/0 | 梯子底 |
| I3 消息与阻尼 | S16.10 | 252 | 186/61/5/0 | S12.6 为 257，S14.10 为 276，20 dB 升到 6 |
| I4 后验 | S16.10 | 256 | 190/61/5/0 | S12.6 为 259；S16.12 和 S14.10 的 20 dB 升到 10 |
| R 软比特 | S8.4 | 253 | 187/61/5/0 | 已是梯子最窄 |

S24.14 在 F、I1、I3、I4、R 上误码都是 256，和双精度的分档相同。I2 的 S24.14 也是 256，饱和 29 次。段内再压，误码可以低于 256，少掉的几乎都在 0 dB。

## 拼接

六段按上表最窄档直接接在一起：F S14.10、I1 S10.6、I2 S8.4、I3 S16.10、I4 S16.10、R S8.4。整机误码 275，分档 201 / 67 / 7 / 0。0 dB、10 dB、20 dB 都比双精度多，30 dB 仍是 0。各段单独少掉的误码不能相加。

I2 的 S8.4 是唯一在单独运行时就把 20 dB 从 5 推到 7 的最窄档。只把 I2 改成 S10.6，其余五段仍用最窄档，再仿真一次：整机误码 243，分档 177 / 61 / 5 / 0。10 dB、20 dB、30 dB 与双精度相同，0 dB 从 190 降到 177。与 float 的硬判差是 103 bit。

其余改法没有更低的整机误码。把 F、I1 或 I3 放回 S24.14，整机是 255、273、274。把 R 放宽到 S16.10，整机升到 280。另一组改动较小的位宽（F S24.14、I1 S20.12、I2 S16.12、I3/I4/R S16.10）整机 247，硬判差 13 bit，高于 243。

蓝图因此取整机这一次的结果，不取六段最窄档的直接拼接。

| 过程 | 蓝图格式 | 这段里收成这个格式的数 |
|---|---|---|
| F | S14.10 | y、H、两个方差、Gram、右端、中心、协方差、评分方差、分数、local |
| I1 | S10.6 | A2 的输入、权重、乘积、累加、输出，α |
| I2 | S10.6 | exp、指数和、概率、均值、方差、残差、加权能量、mix 三个数、λ、ai |
| I3 | S16.10 | A13 的输入、权重、乘积、累加、输出，raw、rate、两条阻尼乘积、阻尼和、β |
| I4 | S16.10 | A5 的输入、权重、乘积、累加、z |
| R | S8.4 | 24 个 LLR。该格式最大绝对值 7.9375，±20 的限幅结果会再被夹到端点 |

I1 到 I4 每帧 3 轮。β 从 I3 回到下一轮 I1。只有末轮 z 进入 R。排序索引不在这张位宽图里。F 的 4×4 分解仍是双精度，图上的 S14.10 是 Gram、右端、中心和协方差的格式。

乘积和累加是双精度乘完再量化，顺序是按列的非零项。图上的格式是每个数写出时的位宽。整数乘加能不能按这个位宽做，还要逐步看溢出，这一步没有做。80 帧上的 243 次误码也还不是整机冻结条件，能量没有测。
